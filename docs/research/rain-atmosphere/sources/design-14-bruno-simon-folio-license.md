## Notes for design brief — [confirmed, primary source]

- Plain MIT, no additional attribution-request README section surfaced in this fetch (unlike Brittany Chiang's repo, which layers a social "please credit me" ask on top of the same license — see design-7). Do not over-read this difference as "Bruno Simon doesn't care about attribution" — his live site (design-4) has its own dedicated in-product mechanism for this (the "Copycats" — actually that's Keita Yamada/p5aholic, see design-6, not Bruno Simon; do not conflate the two). No public copycat-shaming page was found for Bruno Simon specifically in this research pass.
- Practical takeaway unchanged from design-7: MIT license = legally free to learn from and reference technique-wise, but a 3D-driving-game portfolio is such a distinctive, singular concept that reusing its actual premise would read as unoriginal regardless of license. Relevant to this project only as "how one heavily-animated personal site licenses its code," not as a layout/concept to borrow.
