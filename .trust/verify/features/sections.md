- **EP-HOME** — `/` renders hero TOP-LEFT (name, role eyebrow, headline, summary, two CTAs — `justify-start pt-28 md:pt-32`, `min-h-screen`, section `id="top"`) with fixed nav; the sky/city scene owns the lower half of the first viewport. Page column is `max-w-6xl` (nav, main, footer all share it; main and footer carry `w-full` — body is a flex column, and an auto-margined flex item without it shrinks to its content, which is how the footer once rendered a third narrower than the page). The hero is sized with the STABLE viewport unit (100vh = large viewport on phones) and dynamic-viewport units are BANNED from the whole page (don't even write that class token in comments or docs — Tailwind scans everything non-ignored and re-emits the utility): the dynamic unit shrinks while the browser toolbar is visible, which pulled the projects section up to the waterline on iOS Safari and re-laid-out the document on every toolbar collapse mid-scroll (operator screenshots 2026-08-31). Guard (automated): `npm run check` fails on any dvh/svh-family unit in the built CSS, and `npm run smoke` asserts `#projects` doc-top ≥ waterRest + 90css at 390×844. Hero copy carries `.hero-legible` (a tight dark text-shadow halo — towers, signs and rain pass directly behind the words, worst on phones where the megatower sits under the summary) and `.hero-rise` (lines ease in on load, 520ms, CSS-only on prerendered HTML, off under reduced motion); headline is `text-balance` (no orphaned last word). Primary CTA is a FILLED accent pill (dark text on `--accent`), GitHub is the outlined secondary with a translucent fill so the skyline never shows through its label. CTAs, contact links, and the floating pills all carry `min-h-11` (≥44px tap targets). A visually-hidden "Skip to content" link is the first tab stop (`href="#main"`).

Gotchas: content facts live in `src/lib/content.ts` only — copy edits happen there, never inline in JSX (UI labels like "Copy address" are not content facts). Echinoid card must never carry an accuracy percentage (recorded honesty mandate). Custom rules in `globals.css` are UNLAYERED and therefore beat every Tailwind utility regardless of order — the global `:focus-visible` outline cannot be removed with an `outline-*` class (the gallery image button, whose frame clips overflow, insets its ring with a dedicated `.stage-button:focus-visible` rule instead).
