# atmosphere — rain engine + city + descent + audio

Owner code: `src/components/Atmosphere.tsx`, `src/lib/rain/engine.ts`, `src/lib/rain/audio.ts`, depth tokens in `src/app/globals.css`.

- **EP-RAIN** — canvas animates on load (default: motion on unless reduced-motion). Drive: load `/`, screenshot twice ≥1s apart; streaks/ripples must differ; water band (bottom ~14%) shows surface line + ripples when drops land.
- **EP-CITY** — sci-fi skyline behind the rain, above the waterline: three parallax building bands with lit windows, 2–4 pulsing cyan beacons, flying cars crossing in two lanes with light trails (cap 3, spawn every 6–14s). Drive: at scroll 0, screenshot; skyline visible between sky and water. Cars/window toggles: two screenshots ~10s apart differ in car positions or lit windows (cars are sparse — patience, not a bug).
- **EP-SOUND** — lofi rain bed (pink noise, dark voicing, subtle crackle) behind the sound toggle (`aria-label="Toggle rain sound"`). Drive: patch AudioContext + BiquadFilter (see verify.md, before first gesture), click toggle → `window.__ac[0].state === "running"`, aria-pressed=true; click again → after ~1s state `suspended`. Stored pref `rain-sound: "on"` arms a one-time pointerdown on next visit. Underwater muffle: with sound on, at scroll 0 the two master lowpasses read ~3000 Hz; at page bottom they sweep to ~300 Hz (`window.__filters.filter(f => f.type === "lowpass").map(f => Math.round(f.frequency.value))`).
- **EP-DESCENT** — scrolling submerges the camera instead of scrolling the background: within the first ~0.9 viewport the water surface rises past the top of the screen; deeper scroll ramps the scene darker (6-stop ramp to near-black at the footer, never pure black) with god rays near the surface, drifting marine snow, faint abyss glints at depth. DOM panels darken and dim text tiers brighten via `--depth` (0→1). Drive: set `document.documentElement.style.scrollBehavior = "auto"`, then scrollTo 0 / 0.5vh / 1.5vh / mid / bottom with ~0.8s wait before each screenshot; read `getComputedStyle(document.documentElement).getPropertyValue("--depth")` at each stop (monotonic rise); text must stay legible in every screenshot; scroll back to 0 restores the surface scene (city + rain).
- **EP-MOTION-PREF** — reduced-motion users get a static frame by default. Drive the media-query init path with a Playwright context `{ reducedMotion: "reduce" }` (motion toggle loads aria-pressed=false, frame frozen); the rain toggle (`aria-label="Toggle rain animation"`) drives the same path interactively: off → animation halts, static frame remains (city + flat water, no cars); scrolling while static still updates submersion/darkness (re-rendered static frames).
- **EP-PERSIST** — toggles persist. Drive: set rain off, reload, aria-pressed stays false and canvas static; localStorage `rain-motion` = "off".

Gotchas: canvas is `fixed inset-0 -z-10` under a body background — a fully black screenshot at scroll 0 means the negative-z stack broke (at the footer, near-black is correct). Engine pauses on `visibilitychange`. City is seeded per mount: same skyline across resizes within a visit, new skyline per reload.
