# atmosphere — rain engine + city + descent + music + smooth scroll

Owner code: `src/components/Atmosphere.tsx`, `src/lib/rain/engine.ts`, `src/lib/rain/audio.ts`, `src/lib/scroll.ts`, depth tokens in `src/app/globals.css`.

- **EP-RAIN** — canvas animates on load (default: motion on unless reduced-motion). Drive: load `/`, screenshot twice ≥1s apart; streaks/ripples must differ; water band (bottom ~14%) shows surface line + ripples when drops land.
- **EP-CITY** — sci-fi skyline behind the rain, above the waterline: three parallax building bands with lit windows, 2–4 pulsing cyan beacons, flying cars crossing in two lanes with light trails (cap 3, spawn every 6–14s). Drive: at scroll 0, screenshot; skyline visible between sky and water. Cars/window toggles: two screenshots ~10s apart differ in car positions or lit windows (cars are sparse — patience, not a bug).
- **EP-SOUND** — two-bed depth-reactive score behind the music toggle (`aria-label="Toggle background music"`). SURFACE world (through the muffle): bright beatless keys Cmaj9→Fmaj9→Am11→Gadd9 (7s per chord, 28s loop; the vi is voiced third-less so it never turns sad), keys lowpass 2400 Hz, sine bass (65.41/87.31/110/98), wow/tremolo, vinyl crackle, C-major-pentatonic bell plucks (C5–C6 pool) through a 0.31s feedback delay, plus light rain. DEEP world (bypasses the muffle, native to the water): three sine pads voicing open root/fifth/octave per chord (no thirds — vast, not sad) through a fixed 850 Hz lowpass, per-voice swell LFOs, chords gliding over 1.6s (vs 0.12s in the air), rare 2.8s root bells. ~20 persistent oscillators; plips/plucks/bells add transients, so assert `>= 20`. **Default ON**: a fresh visitor's pill is lit before any gesture (`aria-pressed=true`), no AudioContext exists until the first qualifying gesture (pointerdown/keydown/touchend — wheel/scroll can't unlock audio in any engine), and the armed window listeners skip clicks on the pill itself so the button's own handler starts (not toggles off) the music — pin all three. Chord evidence from `__oscs` within the first 7s: 196/246.94/293.66/329.63 ×2 each (Cmaj9 detuned pairs), bass 65.41, deep 130.81/196/261.63; after +7s the top voice moves to 392 (Fmaj9's G4) and bass to 87.31. Toggle off → fade ~1s → state `suspended`. Muffle: the two lowpasses reading ~3000 at surface (of 6 total: rain body ~1400 gust-swept, rumble 90, keys 2400, deep 850, muffle pair) complete the sweep to ~300 by full submersion (combined depth 0.4 ≈ 0.9 viewport of scroll), hold to the footer, recover at return. Crossfade evidence: snapshot every `__gains` value at the surface, submerge, re-snapshot — exactly ONE gain goes <0.02 → 0.25–0.42 (the deep bus, target 0.34); rumble rises only to ~0.03 and sparkle dies, so the filter can't confuse them. Loudness: analyser tee on `ctx.destination` (verify.md) → surface RMS ≈ −11 dBFS ±1.5, peak ≈ −1 (master feeds a DynamicsCompressor limiter, threshold −4); below ≈ −16 dBFS is the too-quiet regression. Submerged RMS lands ≈ −16 ± 2 dBFS — calmer than the surface but present (the pads replace the muffled keys); near-silence at depth means the deep bus is disconnected. Vinyl crackle is depth-independent — it persists underwater.
- **EP-SCROLL** — wheel + paging keys glide the page through a single 8/s ease (`src/lib/scroll.ts`); the engine camera tracks `scrollY` directly (no second ease), so water and text move on the same frame; touch, scrollbar drags, and anchors stay native. Drive: synthetic cancelable WheelEvent → `defaultPrevented` true (false under reduced motion); `page.mouse.wheel(0,120)` ×5 → rAF scrollY trace shows dense small steps, strictly monotonic, total = sum of wheel deltas; PageDown ≈ 0.85×vh; Home glides back to 0 (blur focus first — the key guard ignores focused controls); Space on a focused toggle activates the button and must NOT scroll; anchor click glides via CSS smooth and the smoother adopts the drift — use `a[href="#projects"]`, never `a[href^="#"]` (matches the logo `href="#"`). Gotcha: trace glides from non-zero y — negative-dt backward jerks clamp invisibly at y=0 (see verify.md).
- **EP-DESCENT** — scrolling submerges the camera instead of scrolling the background: within the first ~0.9 viewport the water surface rises past the top of the screen; deeper scroll ramps the scene darker (6-stop ramp to near-black at the footer, never pure black) with god rays near the surface, drifting marine snow, faint abyss glints at depth. DOM panels darken and dim text tiers brighten via `--depth` (0→1). Drive: set `document.documentElement.style.scrollBehavior = "auto"`, then scrollTo 0 / 0.5vh / 1.5vh / mid / bottom with ~0.8s wait before each screenshot; read `getComputedStyle(document.documentElement).getPropertyValue("--depth")` at each stop (monotonic rise); text must stay legible in every screenshot; scroll back to 0 restores the surface scene (city + rain). Coupling: during a wheel glide, `--depth` matches `0.4 · clamp01(scrollY/(0.9·vh))` frame-for-frame (±0.003) — any onset lag vs the text is the water-lags-scroll bug (see verify.md).
- **EP-MOTION-PREF** — reduced-motion users get a static frame and native scrolling by default. Drive the media-query init path with a Playwright context `{ reducedMotion: "reduce" }`: motion toggle loads aria-pressed=false, frame frozen, wheel probe NOT prevented, native wheel still scrolls. The rain toggle (`aria-label="Toggle rain animation"`) drives the same path interactively: off → animation halts, static frame remains (city + flat water, no cars); scrolling while static still updates submersion/darkness (re-rendered static frames).
- **EP-PERSIST** — toggles persist. Drive: set rain off, reload, aria-pressed stays false and canvas static; localStorage `rain-motion` = "off".

Gotchas: canvas is `fixed inset-0 -z-10` and carries the page's base coat (`bg-background`); body must stay transparent — `html` has a background (overscroll match), which cancels body→root propagation, so any opaque body background paints over the scene. A flat scene-less screenshot at scroll 0 means that stacking broke (at the footer, near-black is correct). Engine pauses on `visibilitychange`. City is seeded per mount: same skyline across resizes within a visit, new skyline per reload. A suspended AudioContext freezes `currentTime`, so the chord scheduler no-ops safely while off.
