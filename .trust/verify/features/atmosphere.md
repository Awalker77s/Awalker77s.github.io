- **EP-SOUND** — two-bed depth-reactive score behind the music toggle (`aria-label="Toggle background music"`). SURFACE world (through the muffle): bright beatless keys Cmaj9→Fmaj9→Am11→Gadd9 (7s per chord, 28s loop; the vi is voiced third-less so it never turns sad), keys lowpass 2400 Hz, sine bass (65.41/87.31/110/98), wow/tremolo, vinyl crackle, C-major-pentatonic bell plucks (C5–C6 pool) through a 0.31s feedback delay, plus light rain. DEEP world (bypasses the muffle, native to the water) is a LOFI GROOVE, not dark ambient: three pad voices as ±7-cent detuned sine PAIRS voicing open root/fifth/octave per chord AN OCTAVE UP from the bass register (roots 261.63/261.63/220/196 — sub-200 Hz pads read as dread, 250–500 Hz reads as warm Rhodes) through a 1400 Hz lowpass whose cutoff wobbles ±35 Hz on a 0.05 Hz LFO, per-voice swell LFOs, two high color voices (B4/D5 over C, gains 0.12/0.10), chords gliding 1.6s. THE BEAT: a 16-step grid derived as CHORD_S/16 per eighth (≈68.6 BPM half-time, phase-locked to the chords, no second clock), kick (sine 130→42 Hz pitch drop, peak 0.16) on 1 and the &-of-3, snare (1500 Hz bandpassed white noise + 200 Hz body, 0.10/0.04) on the backbeat, hats every eighth (6500 Hz bandpass ticks, 0.035, upbeats at 65%) with 58% swing + per-hit ms jitter and velocity variation; drums bypass deepFilter on their own drumSum bus → tanh(1.7) soft-clip shaper → breath; each kick ducks the DRY pad path to 55% (reverb send taps pre-duck so the tail never pumps); snare alone sends 0.2 to the reverb. The kit's level is deepLevel × min(1, abyss/0.15) computed at schedule time — the cursor always advances but hits only schedule once truly under (abyss > 0), so no catch-up burst and the surface stays beatless by construction. Every hit time is clamped to the context clock (max(currentTime + 1ms, swung + jitter)): the drum cursor starts at the context's birth, so a fresh context armed AT DEPTH (visitor reloads while submerged, then clicks) otherwise computes its first hits at t < 0 and `setValueAtTime` THROWS a RangeError (caught live 2026-08-31). Drive: scroll ~2.2 vh deep BEFORE any gesture, click, wait ~3s — no console RangeError and transient drum oscs still accrue. Beat evidence: transient drum oscs accrue ≥3 per ~3s at depth. Abyssal chimes every ~6–15s: three NEAR-harmonic partials 1 : 2 : 3.01 on the chord root ×2, 8ms strike, 1–3.5s decays, on their own UNMUFFLED bus (0.20). A comb-network reverb (4 feedback delays 210/270/330/390ms, feedback ≤0.30, damped at 1800 Hz, wet 0.17 into depthTrim) is fed by pads + chimes + snare sends. WATERLINE ONE-SHOTS: crossing combined depth 0.4 (hysteresis ±0.02, 1s cooldown, armed silently on first setDepth) fires a synthesized plunge going down (lowpass-swept pink noise whoosh 4500→350 Hz + 500→90 Hz bloop + 5 bubble blips, ~0.9s) and a breach coming up (highpass-swept splash 200→5000 Hz + 110→700 Hz whoop + 6 droplet taps, ~1.1s), gain and snappiness scaled by crossing speed, on a dedicated transitionBus joining at MASTER (bypassing muffle AND depthTrim — the live depth automation would wobble a hand-authored envelope). 26 persistent oscillators; plips/plucks/bell partials add transients, so assert `>= 26`. **Default ON + optimistic start** (operator ask 2026-08-31 "sound as soon as I get in"): a fresh visitor's pill is lit before any gesture (`aria-pressed=true`), and ~600ms after mount an OPTIMISTIC enable runs — engines that grant audible autoplay (Chrome media-engagement history, installed PWAs; typically returning visitors) start the score with ZERO interaction, while blocked engines leave the context inaudible (born suspended, or resume() rejected/pending) and the armed qualifying-gesture listeners (pointerdown/keydown/touchend — wheel/scroll can't unlock audio in any engine; a phone's first SWIPE counts via touchend) still start it. The armed listeners skip clicks on the pill itself so the button's own handler starts (not toggles off) the music; `startTicking` is idempotent (tickTimer guard) because the optimistic pending enable and the gesture enable can both resolve. - **EP-SCROLL** — wheel + paging keys glide the page through a single 8/s ease (`src/lib/scroll.ts`); the engine camera tracks `scrollY` directly (no second ease), so water and text move on the same frame; touch, scrollbar drags, and anchors stay native. Drive: synthetic cancelable WheelEvent → `defaultPrevented` true (false under reduced motion); `page.mouse.wheel(0,120)` ×5 → rAF scrollY trace shows dense small steps, strictly monotonic, total = sum of wheel deltas; PageDown ≈ 0.85×vh; Home glides back to 0 (blur focus first — the key guard ignores focused controls); Space on a focused toggle activates the button and must NOT scroll; anchor click glides via CSS smooth and the smoother adopts the drift — use `a[href="#projects"]`, never `a[href^="#"]` (matches the logo `href="#"`). Gotcha: trace glides from non-zero y — negative-dt backward jerks clamp invisibly at y=0 (see verify.md).
- **EP-DESCENT** — scrolling submerges the camera instead of scrolling the background: within the first ~0.9 viewport the water surface rises past the top of the screen; deeper scroll ramps the scene darker (6-stop ramp to near-black at the footer, never pure black) with god rays near the surface, drifting marine snow, faint abyss glints at depth. DOM panels darken and dim text tiers brighten via `--depth` (0→1). Drive: set `document.documentElement.style.scrollBehavior = "auto"`, then scrollTo 0 / 0.5vh / 1.5vh / mid / bottom with ~0.8s wait before each screenshot; read `getComputedStyle(document.documentElement).getPropertyValue("--depth")` at each stop (monotonic rise); text must stay legible in every screenshot; scroll back to 0 restores the surface scene (city + rain). Coupling: during a wheel glide, `--depth` matches `0.4 · clamp01(scrollY/(0.9·vh))` frame-for-frame (±0.003) — any onset lag vs the text is the water-lags-scroll bug (see verify.md).
- **EP-MOTION-PREF** — reduced-motion users get a static frame and native scrolling by default. Drive the media-query init path with a Playwright context `{ reducedMotion: "reduce" }`: motion toggle loads aria-pressed=false, frame frozen, wheel probe NOT prevented, native wheel still scrolls. The rain toggle (`aria-label="Toggle rain animation"`) drives the same path interactively: off → animation halts, static frame remains (city + flat water, no cars); scrolling while static still updates submersion/darkness (re-rendered static frames).
- **EP-PERSIST** — toggles persist. Drive: set rain off, reload, aria-pressed stays false and canvas static; localStorage `rain-motion` = "off".

Gotchas: canvas is `fixed inset-0 -z-10` and carries the page's base coat (`bg-background`); body must stay transparent — `html` has a background (overscroll match), which cancels body→root propagation, so any opaque body background paints over the scene. A flat scene-less screenshot at scroll 0 means that stacking broke (at the footer, near-black is correct). Engine pauses on `visibilitychange`. City is seeded per mount: same skyline across resizes within a visit, new skyline per reload. A suspended AudioContext freezes `currentTime`, so the chord scheduler no-ops safely while off.
