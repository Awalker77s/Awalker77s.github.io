# portfolio

Alexander Walker's developer portfolio — a dark, rainy single page that submerges as you scroll. Everything atmospheric is hand-built: the rain, city, and water are a custom canvas engine (spring-column water surface, seeded skyline under a drifting procedural overcast, baked window bloom, a rippling sliced mirror of the city in the water), and the soundtrack is synthesized live in the Web Audio API — no animation libraries, no audio files.

## The descent

Scrolling is a dive. The camera submerges past the waterline in the first viewport, the scene darkens through a six-stop ramp toward a near-black abyss, DOM surfaces sink with a `--depth` token — and the music changes mood with you: a bright lofi bed (Cmaj9 → Fmaj9 → Am11 → Gadd9, pentatonic bell line) plays at the surface, and as you sink it muffles away (3000 → 700 Hz) while an open-fifth deep-water pad world and a half-time beat crossfade in. A depth readout in the nav counts the metres and names the ocean light zone, pinned to the same stops as the color ramp. Sound is on by default; the first qualifying gesture starts it (autoplay policy), it pauses while the tab is in the background, and both the music and rain toggles persist.

## Run

```bash
npm install
npm run dev
```

Port 3000. Content facts live in `src/lib/content.ts` only — copy edits happen there, never inline in JSX.

Every visit builds a new skyline. Add `?seed=<number>` to the URL to pin one (and its weather) — useful for reproducible screenshots.

## Verify

```bash
npm run lint        # eslint
npm run typecheck   # next typegen + tsc
npm run build       # static export to out/
npm run check       # static guards over out/ (no browser, ~1s)
npm run smoke       # headless drive of the built site
```

`check` and `smoke` exist because every invariant they pin has been broken once: banned viewport units creeping back through Tailwind's scanner, image dimensions drifting from the files, the lightbox leaking a scroll lock, the music pill toggling itself off on the first click. `check` also gates the deploy. `smoke` needs a Playwright Chromium (`npx playwright install chromium`, or `CHROMIUM_PATH=/path/to/chrome`).

The full launch/doctor/drive/evidence recipe is in `.trust/verify.md`, with per-feature expectations in `.trust/verify/features/`. Card screenshots of the public sites regenerate as WebP pairs via `node scripts/shoot.mjs` (inside-the-app captures are documented in the feature notes and are not regenerated by it).

## Deploy

Push to `master` → `.github/workflows/deploy.yml` lints, builds, runs `npm run check`, and publishes `out/` to GitHub Pages. A red gate ships nothing.

## Layout

- `src/lib/content.ts` — every fact on the page, plus the section list the nav and headings share
- `src/lib/rain/engine.ts` — canvas rain/city/water/descent engine
- `src/lib/rain/textures.ts` — procedural textures baked once: clouds, mist, light shaft, caustics, bloom
- `src/lib/rain/audio.ts` — two-bed depth-reactive WebAudio score + rain synth
- `src/lib/scroll.ts` — the single smooth-scroll stage (camera tracks scrollY directly)
- `src/lib/depth.ts` — the waterline constant, the depth stream, depth → metres/zone
- `src/lib/storedFlag.ts` — the persisted on/off preferences (hydration-safe)
- `src/components/Atmosphere.tsx` — canvases + toggles + default-on sound arming
- `src/components/SiteNav.tsx` — nav, scrollspy, depth gauge, phone menu
- `src/components/ProjectCard.tsx` — card, gallery, native-dialog lightbox
- `scripts/check-build.mjs`, `scripts/smoke.mjs` — the two verification scripts
